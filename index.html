01 博客 0 颗星

涡状星系

M51 · 宏象旋涡星系 · 伴星系 NGC 5195

把复杂留给系统，把简单留给用户。

旋臂一圈圈绕回中心。产品也一样：所有路径最后都要回到用户的问题。

这里还没有星星。

02 论文 0 颗星

NGC 1300

棒旋星系 · 波江座

论文回答边界，产品回答取舍。

一根笔直的棒穿过核心，旋臂从两端展开。先有结构，再谈增长。

这里还没有星星。

霍格天体

留白不是缺失，是设计。

这里还没有星星。

04 日常 0 颗星

撒撒的糖盒

我是撒撒的糖盒，AI 产品经理。做过大模型应用，也做过 Agent 从 demo 到上线。习惯先把问题拆到不能再拆，再决定做不做。

比起参数规模，我更关心模型能不能变成用户愿意反复使用的产品。这里记录我的判断、踩过的坑，和一些还没有答案的问题。

把问题想清楚，比把话说漂亮更重要。

所有光都在这里弯折、回头。我的联系方式在周围绕行，选一个。
