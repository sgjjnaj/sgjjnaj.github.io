我是撒撒的糖盒

AI 产品经理，常驻广东。

做过大模型应用，也带过 Agent 从 demo 到上线。我的方法很固定：先把问题拆到不能再拆，再决定做不做；能用一个最小版本验证的，就不写第二版。

我不太相信“模型能力到了，产品自然就成了”。中间还隔着场景选择、交互设计、成本控制和评估闭环，这些才是产品经理的活。

我在做什么

  • 大模型应用：把模型能力翻译成用户能理解、愿意反复使用的功能。
  • Agent 落地：任务拆解、工具调用、失败兜底、评估闭环，一个都不能少。
  • 产品化：把 demo 做成能长期运行的产品，而不是一次性的演示。

这个站用来放我的判断、踩过的坑，和一些还没有答案的问题。写得不一定对，但都是真话。
